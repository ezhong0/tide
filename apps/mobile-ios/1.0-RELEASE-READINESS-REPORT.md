## ❌ BUILD ISSUES (BLOCKING 1.0)

### Critical Build Errors

#### 1. Duplicate Type Definitions (HIGH PRIORITY)
**Status**: 🔴 Blocking compilation

Multiple types defined in multiple locations:

| Type | Location 1 | Location 2 | Action Needed |
|------|-----------|-----------|---------------|
| `APIClientProtocol` | `Core/Protocols/APIClientProtocol.swift` | `Core/Protocols/ServiceProtocols.swift` | Remove from ServiceProtocols |
| `Spacing` | `Core/Design/Spacing.swift` | `Core/Design/DesignSystem.swift` | Consolidate |
| `Typography` | `Core/Design/Typography.swift` | `Core/Design/DesignSystem.swift` | Consolidate |
| `Colors` | `Core/Design/Colors.swift` | `Core/Design/DesignSystem.swift` | Consolidate |
| `APIError` | `Networking/NetworkError.swift` | `Core/Errors/ConfigurationError.swift` | Remove duplicate |
| `AuthError` | `Services/AuthManager.swift` | `Core/Errors/ConfigurationError.swift` | Remove duplicate |

**Fixed by Claude**:
- ✅ `AuthManagerProtocol` (removed from ServiceProtocols.swift)
- ✅ `CalendarDay` (removed from Date+Tide.swift)
- ✅ `EmptyStateView` (renamed DashboardEmptyStateView)

#### 2. Legacy Code Duplication (HIGH PRIORITY)
**Status**: 🔴 Causing build conflicts

Root directory has old/legacy code that conflicts with `TideApp/` directory:
```
Root Level (OLD):
├── Core/
│   ├── Config.swift
│   ├── TideCore.swift
│   └── TideTheme.swift
├── Features/
├── Models/
└── Services/

TideApp/ (CURRENT):
├── Core/
├── Features/
├── Models/
└── Services/
```

**Solution Applied**:
- ✅ Updated Package.swift to exclude root-level duplicates
- ✅ Set `path: "."` with `exclude: ["Core", "Features", "Models", "Services"]`

#### 3. Color System Issues (MEDIUM PRIORITY)
**Status**: 🟡 Compilation errors

SwiftUI color references missing context:
```swift
// Error: cannot be resolved without a contextual type
static let tideSurface = Color(.secondarySystemBackground)
static let tideBackground = Color(.systemBackground)
```

**Fix**: Add `UIColor` context for iOS:
```swift
static let tideSurface = Color(uiColor: .secondarySystemBackground)
static let tideBackground = Color(uiColor: .systemBackground)
```

#### 4. Mock Data Issues (LOW PRIORITY)
**Status**: 🟡 Non-blocking

MockAPIClient has outdated method signatures that don't match updated models.
